Projects

Neural network control of a 3R robot

View code

My MSc project. A computed torque controller loses accuracy when the robot model is wrong, so I trained a feedforward neural network to estimate the extra torque that the mismatch causes and added it to the controller. In simulation, it cut tracking error (RMSE) by 81.9%, 79.1% and 76.8% on the three joints, about 79% on average.

MATLAB, computed torque control, neural networks, robot dynamics

AnnoMI therapist behaviour classifier

View code

Predicts what a therapist is doing (question, reflection, therapist input or other) from the text of counselling dialogue. I compared a TF-IDF and Logistic Regression baseline with a fine-tuned BERT model on 4,882 labelled utterances. BERT reached 77.5% test accuracy and scored higher on every class I compared, including 0.594 vs 0.507 F1 on the smallest class.

Python, PyTorch, Hugging Face Transformers, scikit-learn, NLTK, pandas

Thunderbolt: multi-agent block assembly

View code

A team of five autonomous agents for the Multi-Agent Programming Contest block-assembly scenario. One leader claims tasks and helpers deliver the second block. Agents explore in spirals, merge their separate coordinate frames, recover when stuck and submit tasks together. Includes a Java A* pathfinding action for Jason agents.

Jason (AgentSpeak), Java, multi-agent systems

Pick and place with the DOBOT Magician Lite

View report

A group project where a 3-joint robot arm stacks three blocks. We gave Cartesian targets, let the arm’s inverse kinematics solver find the joint angles, and added raised moves and short pauses so the gripper never released a block while moving. It worked reliably, but only with fixed coordinates, so we proposed camera-based feedback next.

DOBOT Magician Lite, inverse kinematics, trajectory planning
